Privacy

  • The app collects nothing. No account, no analytics, no telemetry. Worksheets stay on your computer.
  • Update check. When it starts, the app asks GitHub whether a newer version is out. That is an ordinary web request (GitHub sees your IP address, as for any web page); nothing about you or your worksheets is sent. Turn it off in Help → Check for updates at startup.
  • AI assistants. The app's MCP server listens only on your own computer. An AI assistant you connect to it can read and change the open worksheet; what that assistant does with it is governed by its own terms.
  • This website uses no cookies and no analytics. It is hosted on GitHub Pages, which keeps the usual server logs.
  • Donations go through GitHub Sponsors or Ko-fi, under their own terms and privacy policies.
