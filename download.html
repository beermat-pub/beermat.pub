The latest version

Free and open source. Or try it in your browser first, with nothing to install.

Windows

  • Installer for Windows 10 and 11, with the beermat command
  • Portable unzip anywhere and run Beermat.exe

macOS

  • Disk image for Apple silicon

Linux

  • .deb Debian, Ubuntu
  • .rpm Fedora, openSUSE

VS Code

  • Extension .bbm files open on their page in VS Code; install with code --install-extension, or Extensions → ⋯ → Install from VSIX

Before you install

The installers aren't signed yet, so your system may warn about them: on Windows choose More info, then Run anyway; on macOS, right-click Beermat in Applications and choose Open. The manual has the details.

Every version, with its notes and the command line on its own, is on the releases page.
